The html document titled "68924550_SolarSystem" can be double clicked to open the solar system project in Chrome. The project contains the sun, planets and moons represented by image textures loaded through URL links. As such, it may take a second to load these textures. The celestial bodies have varying sizes and distances from the sun. 3 moons are included to orbit their planets. Lighting has been implemented through the PointLight class and this has enabled shadows to be cast on the planets therefore creating day/night cycles.

Through the "Orbit Controls" class, it is possible to zoom in/out and change the camera position through the mouse or trackpad. The size of the window can be changed and the scene would be adjusted accordingly thanks to the addEventListener class working on the window.

Finally, in the js folder, the three.js library and add-on "OrbitControls" are included.
